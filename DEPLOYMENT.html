⚡ Quick Start - Use Vercel (Recommended)

Why Vercel? Vercel is made by the creators of Next.js and provides the best hosting for Next.js applications. Deployment takes just 2-3 minutes.

Step 1: Go to Vercel

Visit vercel.com and click "New Project"

Open Vercel
Step 2: Import GitHub Repository
  • Click "Import from Git"
  • Select GitHub (authorize if needed)
  • Find and select: silver-spicy-hut
  • Click "Import"
Step 3: Configure Build Settings

Vercel auto-detects Next.js! Keep defaults:

Setting Value
Framework Next.js
Build Command npm run build
Output Directory .next
Install Command npm install
Step 4: Add Environment Variables

Before deploying, add your Firebase credentials:

  1. Click "Environment Variables"
  2. Add these variables (get values from Firebase Console):
NEXT_PUBLIC_FIREBASE_API_KEY=your_api_key NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your_project.appspot.com NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_sender_id NEXT_PUBLIC_FIREBASE_APP_ID=your_app_id
Step 5: Deploy!

Click "Deploy" and wait 2-3 minutes. Your site will be live at:

silver-spicy-hut.vercel.app

🔥 Firebase Setup (Required)

Your reservation form needs Firebase to store bookings.

1. Create Firebase Project
  1. Go to Firebase Console
  2. Click "Create Project"
  3. Project name: silver-spicy-hut
  4. Accept default settings and create
2. Enable Firestore Database
  1. In Firebase console, go to "Build" → "Firestore Database"
  2. Click "Create Database"
  3. Start in Production Mode
  4. Location: asia-south1 (India)
  5. Click "Enable"
3. Create Firestore Collections

Click "Start collection" and create:

  • Collection ID: reservations
  • Add first document: Skip for now
4. Get Firebase Credentials
  1. Click ⚙️ (Settings) → Project Settings
  2. Scroll to "Your apps" section
  3. Click "Web" icon to create web app
  4. Copy the config object
  5. Add values to Vercel Environment Variables

🌐 Custom Domain (Optional)

Connect your own domain (e.g., spicyhut.in)

In Vercel Dashboard
  1. Project Settings → Domains
  2. Enter your domain: spicyhut.in
  3. Follow DNS configuration steps
  4. DNS changes take 24-48 hours to propagate

🆘 Troubleshooting

Build Fails: "Cannot find module"
rm -rf node_modules package-lock.json npm install npm run build
Environment Variables Not Working
  • ✓ Never commit .env.local to GitHub
  • ✓ Add variables in Vercel dashboard (not in code)
  • ✓ Trigger new deployment after adding variables
  • ✓ Check browser console (F12) for Firebase errors
Images Not Loading
  • ✓ Check if images are in public/images/
  • ✓ Verify image file names match in code
  • ✓ Check browser console (F12 → Console) for 404 errors
Reservation Form Not Saving
  • ✓ Verify Firebase Firestore is set up
  • ✓ Check if environment variables are added in Vercel
  • ✓ Open browser console (F12) and look for Firebase errors
  • ✓ Verify Firebase credentials are correct
