## Image Guidelines

1. **Format**: JPG or WebP
2. **Size**: 1920x1080 for hero images, 800x800 for food items
3. **Quality**: 85% compression for gallery, 90% for hero
4. **Naming**: Use descriptive, hyphenated names (e.g., `butter-chicken-naan.jpg`)
